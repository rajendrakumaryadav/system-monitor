# System Monitor — extension directory

This directory is the GNOME Shell extension itself. Its name **must** match
the `uuid` field in [`metadata.json`](metadata.json):

```
system-monitor@rajendrayadav.github.io
```

See the [project README](../README.md) for features, settings, screenshots and
troubleshooting.

---

## Install

The bundled script installs into
`${XDG_DATA_HOME:-$HOME/.local/share}/gnome-shell/extensions/<uuid>`, compiles
the GSettings schema and enables the extension:

```bash
./install.sh
```

It can also be run from the repository root:

```bash
./system-monitor@rajendrayadav.github.io/install.sh
```

Restart GNOME Shell afterwards:

- **X11:** `Alt+F2`, type `r`, press `Enter`.
- **Wayland:** log out and log back in.

## Uninstall

```bash
./install.sh --uninstall
```

This disables the extension and removes its directory. Settings are kept; to
reset them as well:

```bash
gsettings reset-recursively org.gnome.shell.extensions.system-monitor
```

## Package for extensions.gnome.org

```bash
./install.sh --pack            # zip next to this directory
./install.sh --pack /tmp/out   # or choose an output directory
```

Development-only files (`install.sh`, `.gitignore`, `README.md`, `LICENSE`)
and compiled schemas are excluded from the zip.

## Contents

| Path | Purpose |
| --- | --- |
| `extension.js` | Panel widget, quick menu, sensor reading and update loop. |
| `prefs.js` | libadwaita preferences window. |
| `metadata.json` | Extension identity and supported shell versions. |
| `icons/*.svg` | Bundled symbolic icons, recoloured per metric. |
| `schemas/*.xml` | GSettings keys and defaults. |
| `schemas/gschemas.compiled` | Generated by `glib-compile-schemas`; never edited or shipped. |
| `install.sh` | Install, uninstall and package helper. |
| `README.md` | This file. |
| `LICENSE` | MIT licence. |
| `.gitignore` | Ignores build artefacts and editor noise. |

Settings schema: `org.gnome.shell.extensions.system-monitor`
(path `/org/gnome/shell/extensions/system-monitor/`).

## Development quick checks

```bash
# JavaScript syntax
cp extension.js /tmp/extension.mjs && node --check /tmp/extension.mjs
cp prefs.js     /tmp/prefs.mjs     && node --check /tmp/prefs.mjs

# GSettings schema
glib-compile-schemas --strict --dry-run schemas

# metadata.json
python3 -m json.tool metadata.json >/dev/null
```

Reload after editing JavaScript:

```bash
gnome-extensions disable system-monitor@rajendrayadav.github.io
gnome-extensions enable  system-monitor@rajendrayadav.github.io
```
